# kolossal-media

Médias publics des comptes Kolossal / GLP-1 TUTO / HIROW, utilisés par Buffer.
Tout ce qui est ici est destiné à être publié sur les réseaux.

- `media/AAAA-MM/` : visuels (stories, carrousels, couvertures) et vidéos
- Lien à donner à Buffer : `https://raw.githubusercontent.com/noblins/kolossal-media/main/media/...`
- `queue/*.txt` : vidéos HeyGen à rapatrier. Une ligne par vidéo : `media/AAAA-MM/nom.mp4 https://...heygen.ai/...`
  Le workflow « Récupérer les vidéos HeyGen » les télécharge, les range dans `media/` et vide la file.
